# 《代数几何学原理 I–III》大陆简体中文版

本版本是 Alexander Grothendieck 与 Jean Dieudonné 的 *Éléments de géométrie algébrique* 第一卷至第三卷的独立、非官方大陆简体中文累计工作版。公开内容包括 EGA I、EGA II、EGA III-1 与 EGA III-2，共四个可直接阅读的 PDF，合计 680 页；各册都同时提供完整单文件 LaTeX 和可重建该册的模块化源代码 ZIP。

## 下载顺序

每册都严格按以下顺序排列：

1. PDF 阅读版；
2. 包含该册全部正文的直接下载单文件 LaTeX；
3. 包含驱动文件、模块化正文、前导文件、资源文件、构建说明及源文件清单的完整源代码 ZIP。

EGA I 的 PDF 排在全部文件首位并用作 Zenodo 阅读预览。QA、来源锁、清单和生产记录均排在四册的阅读与编辑文件之后，不再占据读者入口。

## 覆盖范围

- **EGA I**：卷首、引言、第 0 章、第 I 章至 I.10.15.7、参考文献、记号索引、术语索引、目录、收稿日期与印刷信息；214 页。
- **EGA II**：卷首、§§1–8 至 §8.14.14、参考文献、索引、目录及第一号《勘误与增补》至印刷页 222；206 页。
- **EGA III-1**：第 0 章续篇与第三章前半部、参考文献续篇、索引、目录及终止材料；166 页。
- **EGA III-2**：第三章后半部及第二号《勘误与增补》至封存终点；94 页。

EGA IV 尚未包含在本次版本中；它将在同一 GitHub 仓库和 Zenodo 概念下作为后续累计版本加入，不会另建竞争谱系。

## 来源、构建与核验

数学内容以 NUMDAM 法文印本及受控的法文外交式文本为依据；经验证的英文文本仅作次要比较材料，不凌驾于法文权威。已由法文 Canon 接纳的订正以可逆来源说明进入中文阅读层，尚未裁定的疑点按印刷原文保留。

四册均完成结构、公式、标签、交叉引用、字体、字形、文本提取、链接、页面几何和逐页视觉检查。新补充的 EGA I 与 EGA II 直接单文件 LaTeX 已分别经过四遍串行 LuaLaTeX 重建；其 420 页输出与既有公开 PDF 的页面几何、提取文本和 72 dpi 灰度渲染逐字节一致。EGA III 两册由公开的直接单文件 LaTeX 确定性构建并完成全部 260 页的视觉核验。这里的“生产者完成”不冒充独立中文学术认证。
