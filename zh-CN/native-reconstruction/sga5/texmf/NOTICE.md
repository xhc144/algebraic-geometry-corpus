# Standard TeX runtime dependencies

The `tex/` tree contains unmodified runtime macro files from the free TeX Live 2024 final packages ctex, xeCJK, zhnumber and ulem. Existing copyright and licence headers are retained. These are standard independently maintained dependencies, not translated source content. No fonts are included. The installed TeX distribution supplies the remaining standard packages and system fonts.

Obtained from the public TUG historical TeX Live mirror at `https://ftp.math.utah.edu/pub/tex/historic/systems/texlive/2024/tlnet-final/archive/` (ctex.tar.xz, xecjk.tar.xz, zhnumber.tar.xz), and the public CTAN mirror `https://mirrors.mit.edu/CTAN/macros/latex/contrib/ulem/ulem.sty`. The 2024 versions are used for compatibility with the installed LaTeX2e 2024-11-01 engine. Macro files identify their authors and LPPL licensing terms in their headers.
