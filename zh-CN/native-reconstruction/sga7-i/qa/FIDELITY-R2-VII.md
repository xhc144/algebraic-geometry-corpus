## 需显式登记的原稿数学疑误

下列两项由英中共同继承，不能算作译者独自引入的错误。建议根任务在源缺陷记录中保留原读法，再决定采用所列校正；不应悄悄改称原文就是校正后的形式。

### S1 — 3.3.2.1 第一个自然函子的源遗漏 prime（组件 86，中文第 1362 行）

当前英文和中文第一个展示式均为：

```tex
\underline\Psi_{L_\bullet}(A)
\longrightarrow
\underline\Psi_{L_\bullet}([A\longrightarrow A''])
```

建议仅在该式第一项改为：

```tex
\underline\Psi_{L_\bullet}(A')
\longrightarrow
\underline\Psi_{L_\bullet}([A\longrightarrow A''])
```

证据：

1. 前一式固定短正合列 `0→A'→A→A''→0`。
2. 同一段紧接着的第二个展示式明确写 `\underline\Psi(A')→\underline\Psi([A→A''])`。
3. 随后的证明以 `X'=Ker ρ` 构造核 `A'≃Ker v` 上的扩张，正好给出来自 `A'` 的范畴，而不是来自整个 `A` 的范畴。
4. **法文 PDF 192／书页 187** 的第一个展示式确印 `Ψ(A)`，而同页下面印 `Ψ(A')`；故是原印已存在的内部不一致，不是英文 OCR 单独造成。

判断：校正为 `A'` 的依据充分，优先级高。这里涉及函数的源对象，不能只当排版差异忽略。

### S2 — 3.3.3 的“被支配”对象缺 prime 的高度可信疑误（组件 86，中文第 1379 行）

当前：

```tex
使 $E$ \underline{被 $E_0$ 支配}，即存在态射 $E_0\longrightarrow E'$。
```

建议：

```tex
使 $E'$ \underline{被 $E_0$ 支配}，即存在态射 $E_0\longrightarrow E'$。
```

证据：定义先把任意 `E` 送到覆盖单态射 `A→A'` 的对象 `E'`，随后所要求的实际态射是 `E0→E'`。本段证明也先把 `(X,α)` 送到扩张分裂的 `(X',α')`，再断言后一个对象被 `E0` 支配。因此相应宾语应为 `E'`。**法文 PDF 193／书页 188** 在此也印无 prime 的 `E`，却紧接着明确给出 `E0→E'`。当前中文忠实复现这一不一致。

判断：这是很可能的原印缺 prime，建议显式校正；保留原文读法及理由，不能仅凭中文语感静默更换。
