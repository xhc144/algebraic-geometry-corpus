## 建议整合的具体改动

### R2-VIII-01: 一处箭头说明仍是英文缩写

位置: 组件 97, 图 (2.1.14.6), 中文源第 795 行. `incl.` 是描述包含映射的文字缩写, 不是必须保留的人名或数学对象记号. 为符合正文文字完整译成中文的要求, 建议只翻译此标签.

修改前:

```tex
   \arrow[dr,"\mathrm{incl.}"']&&
```

修改后:

```tex
   \arrow[dr,"\text{包含}"']&&
```

箭头方向、附着点和两端对象不改. 这是局部文字未译, 不是证明或配对方向错误.

### R2-VIII-02: 可选的次数术语明确化

位置: 组件 101, 2.3.11 证明 d), 中文源第 1336、1360 行. 英文两处均为 `degree-one homomorphism`. 现译“一次同态”在上下文中可理解, 并未导致图中次数改变; 但改成“次数为 1 的同态”可避免被读成线性或一次多项式的含义. 这是可选措辞修订, 不将其列为实质错译.

第 1336 行的片段, 修改前:

```tex
因而它由一次同态
```

修改后:

```tex
因而它由次数为 1 的同态
```

第 1360 行的片段, 修改前:

```tex
由复形的一次同态
```

修改后:

```tex
由复形的次数为 1 的同态
```

本轮没有直接实施这些改动, 没有编辑章节文件、数学公式或主文件; 由主代理决定整合并重新构建.
