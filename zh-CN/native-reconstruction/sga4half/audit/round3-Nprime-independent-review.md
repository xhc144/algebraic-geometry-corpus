所述精确命题 **(C) ⇔ (E−1) 成立**，在三角范畴A、厚三角子范畴B及Verdier商的假设下，两方向证明均可闭合。所给 `K^b(Ab)` / 有界无环复形反例也成立：仅补 `N′∈B` 不能得到原(e)的零次Hom满射性。

## (C) ⇒ (E−1)

记T=Y[-1]。任取商中从QX到QT的态射，以左屋顶

`X ←s Z →u T`

表示，其中Cone(s)∈B。补三角

`Z →s X →f N →d Z[1]`。

1. 定义 `g=u[1]d:N→T[1]=Y`。类型正确；`df=0` 给出 `gf=0`。
2. 用(C)得到 `h:X→N′`、`i:N′→N`，其中N′∈B，`ih=f`、`gi=0`。
3. 补三角 `Z′ →t X →h N′ →d′ Z′[1]`。其锥N′∈B，所以t∈S。
4. 由 `ih=f`，对旋转后的两个三角施用TR3；`id_X`、`i` 可补成 `v[1]:Z′[1]→Z[1]`。三角态射的两个关系为
   `di=v[1]d′`、`sv=t`。
   旋转中末箭头为 `−s[1]`、`−t[1]`，负号两侧相消，故后一等式没有额外负号。
5. 因此 `(uv)[1]d′=u[1]di=gi=0`。移位后等价于
   `uv d′[-1]=0`。
6. 对三角 `N′[-1] → Z′ →t X → N′` 施加 `Hom_A(−,T)`，所需部分是
   `Hom_A(X,T) → Hom_A(Z′,T) → Hom_A(N′[-1],T)`。
   第二箭头为沿 `d′[-1]` 的预合成，至多差一个旋转符号；其核不受该符号影响。正合性得到 `w:X→T`，满足 `wt=uv`。
7. `Q(s)Q(v)=Q(t)`，而Q(s)、Q(t)可逆。于是
   `Q(u)Q(s)^{-1}=Q(uv)Q(t)^{-1}=Q(w)`。

这证明满射性。此计算不需另行假定v∈S。事实上本处也可由八面体公理及B对移位、三角的封闭性证明S的二取三性，进而得到v∈S；原分析没有依赖这一步。

## (E−1) ⇒ (C)

给定 `X →f N →g Y`、N∈B及gf=0，仍补三角

`Z →s X →f N →d Z[1]`。

1. `Hom_A(−,Y)` 的正合部分为
   `Hom_A(Z[1],Y) → Hom_A(N,Y) → Hom_A(X,Y)`。
   所以存在 `a:Z[1]→Y` 使 `g=ad`。取 `u=a[-1]:Z→Y[-1]=T`，得到所用公式 `g=u[1]d`。类型与移位均正确。
2. 用(E−1)取 `w:X→T`，使 `Q(u)Q(s)^{-1}=Q(w)`；乘以Q(s)即得 `Q(u−ws)=0`。
3. Verdier局部化的左分式零判据给出某 `v:Z′→Z`、v∈S，使
   `(u−ws)v=0`，即 `uv=wsv`。
   此处需要的是在原范畴A中的态射为零，而不是仅知道它通过B分解；分式演算确实提供这个加强后的分母细化。A的Verdier分母S允许左屋顶及该零判据。
4. 令t=sv∈S，补三角
   `Z′ →t X →h N′ →d′ Z′[1]`。
   定义S保证N′∈B（不同锥同构，不影响属于B）。
5. 对 `sv=t`、`id_X` 施用TR3，得到 `i:N′→N`，满足 `ih=f`、`di=v[1]d′`。
6. 计算
   `gi=u[1]di=(uv)[1]d′=(wt)[1]d′=w[1]t[1]d′=0`。
   最后一步是三角中相邻箭头复合为零：`t[1]d′=0`，同样不受旋转负号影响。

所以N′、h、i满足(C)。没有倒置TR3箭头，也没有遗漏额外移位。

## 反例的独立核验

取 `A=K^b(Ab)`，B为有界无环复形构成的全子范畴。

- B对移位与锥封闭；其同伦直和因子亦无环，因为上同调函子保存回缩。因此B确为厚三角子范畴。
- 商 `K^b(Ab)/B` 就是 `D^b(Ab)`；分母为拟同构。
- 令M=Z/n，n>1，X=M[0]、Y=M[1]。于是Y[-1]=M[0]。
- `Hom_K(M[0],M[0])=Hom_Ab(M,M)=Z/n`，且自然映射到 `Hom_D(M[0],M[0])` 为同构。后一个等式来自Ab在其导出范畴中的标准全忠实嵌入，也可由M的两项自由消解直接计算。因此(E−1)成立；由上面已独立验证的引理，(C)成立。
- `Hom_K(M[0],M[1])=0`：按上同调移位约定，目标唯一非零项在次数−1，源唯一非零项在次数0，没有非零零次链映射。
- `Hom_D(M[0],M[1])=Ext^1_Z(M,M)=Z/n`。用自由消解 `0→Z →n Z→M→0` 施加Hom(−,M)，所得微分为零，故一次Ext为M≠0。

因此原(e)对应的映射是 `0→Z/n`，不满射，而加N′∈B的(C)确成立。该反例无需假定n为素数。

必须注意：A中的等式是**同伦类的等式**。若误把gi=0、ih=f解释为代表链映射逐项严格相等，会得到更强且并未证明的链级命题；这不是原精确引理的内容。
