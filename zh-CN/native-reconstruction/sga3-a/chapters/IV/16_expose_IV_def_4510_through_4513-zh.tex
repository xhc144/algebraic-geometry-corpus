暂时回到任意拓扑的情形, 并作\SGARefLink{sga3:iv:definition:4:5:10}{如下定义}.

\medskip
\noindent\SGARefTarget{sga3:iv:definition:4:5:10}\textbf{定义 4.5.10.}
\textit{设 \(G\to F\) 是 \(\widehat{\mathscr C}\) 中的一个态射.
若对每个 \(F\)-函子 \(H\) 及 \(H\) 的每个加细 \(R\),
典范映射}
\[
\tag{+}\label{sga3:iv:definition:4:5:10:eq:unnamed:01}
  \operatorname{Hom}_{F}(H,G)
  \xrightarrow{\ \sim\ }
  \operatorname{Hom}_{F}(R,G)
\]
\textit{是双射, 则称 \(G\) 是 \emph{\(F\) 上的相对层 (relative sheaf)}.}

命题 \SGARefLink{sga3:iv:proposition:4:5:2}{4.5.2} 立即给出以下推广.

\medskip
\noindent\SGARefTarget{sga3:iv:proposition:4:5:11}\textbf{命题 4.5.11.}
\textit{若 \(F\) 是层, 则 \(G\) 是 \(F\) 上的相对层,
当且仅当 \(G\) 是层.}

\medskip
\noindent\SGARefTarget{sga3:iv:lemma:4:5:12}\textbf{引理 4.5.12.}
\textit{在一个序列}
\[
  X\longrightarrow T\longrightarrow S,
\]
\textit{中, \(X,T,S\) 是 \(\widehat{\mathscr C}\) 的三个对象.
假设 \(X\) 是 \(T\) 上的相对层. 则}
\[
  U=\prod_{T/S}X
\]
\textit{是 \(S\) 上的相对层.}

事实上, 对每个 \(S\)-函子 \(Y\), 有
\[
  \operatorname{Hom}_{S}(Y,U)
  =\operatorname{Hom}_{T}(T\times_SY,X).
\]
若 \(C\) 是 \(Y\) 的一个筛,
则 \(T\times_SC\) 是 \(T\times_SY\) 的一个筛, 立即得到结论.

\medskip
\noindent\SGARefTarget{sga3:iv:corollary:4:5:13}\textbf{推论 4.5.13.}
\textit{只要出现在其中的所有变元都是层,
预层 \(\operatorname{Hom}_{T/S}(X,Y)\),
\(\operatorname{Isom}_{S}(X,Y)\) 及类似的预层就都是层.}

事实上, 所有这些预层都是用纤维积及预层 \(\prod_{T/S}X\)
构造的 (I, \SGARefLink{sga3:i:subsection:1:7}{1.7} 和 II,
\SGARefLink{sga3:ii:section:1}{1}).
所以只需对预层 \(\prod_{T/S}X\)
验证\SGARefLink{sga3:iv:corollary:4:5:13}{此断言};
在此情形中, 它由 \SGARefLink{sga3:iv:proposition:4:5:11}{4.5.11} 和
\SGARefLink{sga3:iv:lemma:4:5:12}{4.5.12} 得到.
