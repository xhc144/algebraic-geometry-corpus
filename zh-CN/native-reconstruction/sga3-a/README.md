# SGA 3 前半部：简体中文原生重建

本目录按锁定的英文重构底本完成全部分配范围的初译：28篇中的前14篇，I、II、III、IV、V、VI-A、VI-B、VII-A、VII-B、VIII、IX、X、XI、XII；另含编者告示、导言和第一卷292条索引。不含XIII及以后各篇。

交付 `sga3-a-zh.pdf`（777页）、`main.tex`、333份外部原生图及内嵌交换图、独立源码包 `sga3-a-source.zip`。295个组件、82219源行全部按源顺序收录。没有PDF页面贴图或图像数学，最终PDF图像对象为零。

底本采用外部哈希和内部逐文件清单验证过的源码ZIP；散装TeX与release manifest不符的缺陷仍明确保留，见 `audit/SOURCE_LOCK.json`。原始文献、官方中译及其他作者目录未被替换。全文翻译授权来自用户明确确认，不从上游许可推断。

封面分别参照原书两卷的黑白扉页、作者排列与疏朗层次；正文保留篇、节、编号条款、脚注和原生交换图层次，用ctex适配中文。中文页码另起；索引页码仍指Polo–Gille重版原页码，条序和重复条目均保留。

全部14篇及卷首、索引已完成独立源译全文对照；输入闭合、脚注、书目及依赖另由独立读者审计。真实编译、PDF目标检查、页面/图形检查与源码ZIP干净重编分别记录于 `audit/BUILD-CURRENT.json`、`PDF-CURRENT.json`、`VISUAL-RESUME.json`、`PACKAGE_REBUILD.json`。
